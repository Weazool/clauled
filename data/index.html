WiFi

Claude OAuth token

How to get your token:
1. Install Claude Code on your computer
2. Run claude setup-token in a terminal
3. Log in through the browser when prompted
4. Copy the token it prints

It starts with sk-ant-oat01- and lasts one year. Requires a Claude Pro, Max, Team, or Enterprise plan.

Leave blank to keep the current token.

If set, the device refreshes the access token automatically when it expires. Found in ~/.claude/.credentials.json as refreshToken.
